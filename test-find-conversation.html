🔍 Find Conversation Between Users API Test

📡 Available API Endpoints

1. Find Existing Conversation:

POST /api/v1/conversations/find-conversation

Returns conversation ID if exists, null if not found

2. Get or Create Conversation:

POST /api/v1/conversations/get-or-create-conversation

Returns existing conversation ID or creates new one

✅ No Authentication Required
