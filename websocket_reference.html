Kitty Chat WebSocket Reference Guide

Note: This page provides reference examples for WebSocket events in Postman. It doesn't actually connect to your server.

Connecting to WebSocket

Two namespaces are available:

  • ws://localhost:3001/direct-chat - For direct messaging
  • ws://localhost:3001/general?auth-token=YOUR_TOKEN - For general notifications

Authentication Flow

1. Server Welcome Message

← Server to Client:

{

}

Sending Messages

Send to Specific User

→ Client to Server: sendMessage event

{
  "recipientId": "recipient-uuid-here",
  "type": "text",
  "content": "Hello, this is a direct message!"
}

Send to Existing Conversation

→ Client to Server: sendMessage event

{
  "conversationId": "conversation-uuid-here",
  "type": "text",
  "content": "Hello, this is a message to a conversation!"
}

New Message Event (Receiving)

← Server to Client: newMessage event

{
  "conversation": "conversation-uuid",
  "message": {
    "id": "message-id",
    "conversationId": "conversation-uuid",
    "senderId": "sender-uuid",
    "type": "text",
    "content": "Hello, this is a message!",
    "createdAt": "2025-07-18T23:20:00.000Z",
    "readBy": []
  }
}

Other Useful Events

Event Name Direction Description Example Payload
typing Send Indicate typing status 
{
  "conversationId": "uuid",
  "isTyping": true
}
markAsRead Send Mark messages as read 
{
  "conversationId": "uuid",
  "messageIds": ["id1", "id2"]
}
deleteMessage Send Delete a message 
{
  "conversationId": "uuid",
  "messageId": "message-id"
}
editMessage Send Edit a message 
{
  "conversationId": "uuid",
  "messageId": "id",
  "newContent": "Updated text"
}
